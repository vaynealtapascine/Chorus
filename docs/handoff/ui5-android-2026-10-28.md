  entry expansion is bounded to 180 ms. State is above the transition hosts; model refreshes and

## Self-inspection corrections

| Before | After | Why |
| --- | --- | --- |
| Presence panel ended at the last avatar | Panel fills the list width | Removes the rectangular gap on the phone. |
| Journal had both shell and journal headers | Journal owns one native header | Matches the source hierarchy and frees writing space. |
| Inactive journal tabs used accent ink | Inactive tabs use secondary ink | Selected state reads clearly. |
| Long channel title clipped abruptly | Ellipsis in the fixed header | Keeps search/menu targets usable. |
| Hanken weights selected one variable file without explicit axes | Explicit 400/500/600/700 `wght` variants | Restores real bold and semibold hierarchy. |
| Returning from info/editor recreated scroll state | List state lives above navigation transitions | Preserves the reading position. |
| Offline chat-directory read displayed a raw transport exception | Directory reads wait for Live and retry on reconnect; failures have readable copy | The connection subtitle explains offline state without a raw URL/error. |

The Hanken mapping follows the pinned Compose API and
[Android's variable-font guidance](https://developer.android.com/develop/ui/compose/text/fonts#variable-fonts).
The local 1.7.6 `ui-text` API was checked before using `FontVariation.Settings`; no version changed.
